WaveMaker Agent can find Marketplace artifacts and work with supported WaveMaker Extension components. Use this workflow when an application needs a reusable component or integration beyond its current project artifacts.

## Find a Marketplace artifact

The agent can search for applicable:

- WaveMaker Extension components
- Prefabs
- Connectors
- Design systems

Describe the required user outcome and constraints before naming a specific artifact. The agent can compare available metadata with the current project platform.

```text
Find a supported chart component for a Native Mobile project.
It must support a selectable data point and the current project version.
Show the candidate before adding it.
```

## Work with extension components

Supported extension workflows cover React Native components and supported React-based Web components. The exact artifact and workflow depend on the project platform.

State whether the task is to discover, install, configure, generate, or update the component. Include the page where it will be used and the data or events it must expose.

## Review third-party and reusable artifacts

Before keeping the result:

- Confirm project and runtime compatibility.
- Review the artifact's source, ownership, version, and license.
- Check required configuration and external services.
- Verify variables, properties, events, and bindings.
- Preview the component in the application.

Marketplace availability and artifact metadata can change. Use the current search result and project compatibility information rather than relying on a name from an older project.
