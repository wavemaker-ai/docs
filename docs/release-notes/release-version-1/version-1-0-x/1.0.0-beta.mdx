WaveMaker announces the release of WaveMaker AI 1.0.0 Beta. This release is intended for early adopters and developers who want to explore the capabilities of the WaveMaker platform.

For details about the technology stack upgrades, refer to [Technology Stack](/tech-stack).

## 1.0.0-BETA-RC5

*Release date: 29 June 2026*

<TabsWrapper>
  <TabItem name="Features">
    <Accordian title="Platform">
      - ### Suggested next actions in AI chat <Pill type="web" />

        AI Chat now surfaces relevant next actions at the end of a conversation, enabling users to quickly continue workflows, take follow-up actions, and maintain momentum without manually determining the next step.
    </Accordian>
  </TabItem>

  <TabItem name="Enhancements">
    <Accordian title="Platform">
      - ### Enhanced context discovery and selection in AI assistant input <Pill type="web" />

        Typing @ now directly opens context suggestions with grouped categories and improved filtering, making it faster to find and insert relevant context without navigating multiple trigger levels.

      - ### Enhanced change tracking and agent activity visibility in AI chat <Pill type="web" />

        Redesigned the changes section, improved visibility of available updates, and introduced clearer agent activity and execution status indicators to provide better insight into AI-generated actions and progress.
    </Accordian>
  </TabItem>

  <TabItem name="Bug Fixes">
    <Accordian title="User Interface" />

    <Accordian title="Backend" />

    <Accordian title="Platform">
      - ### Context suggestion filtering and placement fixes <Pill type="web" />

        Fixed issues that prevented context suggestions from filtering correctly after pasting input and caused selected suggestions to appear in the wrong location after selection.
    </Accordian>
  </TabItem>
</TabsWrapper>

## 1.0.0-BETA-RC4

*Release date: 15 June 2026*

<TabsWrapper>
  <TabItem name="Features">
    <Accordian title="Platform">
      - ### Export AI session as downloadable ZIP <Pill type="web" />

        Export your AI session — including conversation history, uploaded files, and session context — as a ZIP archive.

      - ### Upload resources to an AI session <Pill type="web" />

        Upload project resources directly into an AI session for use during agent conversations.

      - ### Live context window usage during agent conversations <Pill type="web" />

        The current context window usage is now displayed live in the UI while an agent conversation is in progress.

      - ### Automatic conversation history compaction <Pill type="web" />

        The AI agent automatically compacts long conversation histories to keep responses fast and context relevant.

      - ### Autocode project sync support with merge framework <Pill type="web" />

        Seamlessly sync Autocode projects with merge framework support for improved collaboration and version control.

      - ### Web and Mobile builder separation for Design2Code projects preview <Pill type="web" /> <Pill type="mobile" />

        Separate web and mobile builders for Design2Code project previews to support better scalability and streamlined development workflows.
    </Accordian>
  </TabItem>

  <TabItem name="Enhancements">
    <Accordian title="Platform">
      - ### Sync latest Studio changes to existing conversations <Pill type="web" />

        Conversations now reflect the most recent project changes made in Studio without requiring a new session.
    </Accordian>
  </TabItem>

  <TabItem name="Bug Fixes">
    <Accordian title="User Interface">
      - ### Time widget value cleared automatically <Pill type="web" />

        Fixed a React app issue where values entered into the Time widget were cleared unexpectedly.

      - ### Page unresponsive on Switch widget change in Figma-generated apps <Pill type="web" />

        Fixed React pages becoming unresponsive when toggling the Switch widget value in apps generated from Figma designs.

      - ### Auto layout incorrect in Figma-imported projects <Pill type="web" />

        Fixed auto layout not rendering correctly when a project was imported from a Figma design.

      - ### `formatpattern` attribute missing from datatable markup <Pill type="web" />

        Fixed `formatpattern` not being written to the datatable markup when configured.
    </Accordian>

    <Accordian title="Backend">
      - ### Connection pool for LangGraph Postgres checkpointer

        Fixed idle-timeout failures by switching the LangGraph Postgres checkpointer to use a connection pool.

      - ### REST service proxy failing with negative target port

        Fixed REST service calls failing with "Target port must not be negative" when the app proxy was configured with include/exclude URLs.
    </Accordian>

    <Accordian title="Platform">
      - ### REACT - Page params not working <Pill type="web" />

        Fixed page parameters not being passed or applied correctly in React app deployments.

      - ### REACT - Authorization not working in React deployment <Pill type="web" />

        Fixed authorization checks failing in React app deployments.
    </Accordian>
  </TabItem>
</TabsWrapper>

## 1.0.0-BETA-RC3

*Release date: 04 June 2026*

<TabsWrapper>
  <TabItem name="Features">
    <Accordian title="Platform">
      - ### Custom instructions via Agents.md <Pill type="web" /> <Pill type="mobile" />

        Add an `Agents.md` file to your project to provide custom instructions that AIRA agents follow automatically when building the app.
    </Accordian>
  </TabItem>

  <TabItem name="Enhancements">
    <Accordian title="Platform">
      - ### Selective container patching in Instance Patch API

        The Instance Patch API now accepts a `patchComponents` parameter to update individual containers selectively without reloading the full instance.
    </Accordian>
  </TabItem>

  <TabItem name="Bug Fixes">
    <Accordian title="User Interface">
      - ### Tab component exposing getter methods as callable functions <Pill type="web" />

        Fixed getter properties on the tab component (e.g., `isFirstTabPane`) being incorrectly exposed as callable methods.

      - ### Number formatter not applied to bound widget <Pill type="web" />

        Fixed number formatters such as thousand separator not taking effect when bound to a widget property.
    </Accordian>

    <Accordian title="Backend">
      - ### Swagger not refreshing after Java model class change

        Fixed Swagger failing to regenerate when a Java service model class was updated, whether used as a return type, parameter, or nested model.

      - ### Authorization header gets x-wm- prefix on REST service import

        Fixed REST service import adding an unwanted `x-wm-` prefix to the `Authorization` header during design time.

      - ### Custom formatter code generated in app.js instead of formatters.js

        Fixed custom formatter code being written to `app.js` instead of the correct `formatters.js` file.

      - ### API-aware live variable initialised with empty filterExpressions

        Fixed `createApiAwareVariable` setting `filterExpressions` to `{}` on a live variable, which caused a downstream validation error.
    </Accordian>

    <Accordian title="Platform">
      - ### AIRA i18n skill not generating app.locale bindings for static texts <Pill type="web" />

        Fixed the AIRA i18n skill failing to replace static page texts with `app.locale` bindings when localizing a page.

      - ### Wizard callback events lose parameters after markup save <Pill type="web" />

        Fixed cancel and done callback events on the wizard component receiving incorrect parameters when page markup was saved after an attribute change.

      - ### Page markup formatting inconsistent before save <Pill type="web" />

        Fixed page markup being formatted in ai-studio before save; it is now consistently prettified in Studio.
    </Accordian>
  </TabItem>
</TabsWrapper>

## 1.0.0-BETA-RC2

*Release date: 18 May 2026*

<TabsWrapper>
  <TabItem name="Features">
    <Accordian title="User Interface">
      - ### Screenshot-to-Code for Mobile (BETA) <Pill type="mobile" />

        Convert a screenshot of a mobile UI into a working WaveMaker mobile page with auto-generated components and layout.

      - ### React output preview in Studio (BETA) <Pill type="web" />

        Preview the generated React output of your app directly inside Studio without switching contexts.
    </Accordian>

    <Accordian title="Platform">
      - ### AIRA chat rebuilt on AG UI protocol <Pill type="web" />

        The AIRA chat interface now runs on the AG UI protocol, replacing Theia for a more responsive and extensible experience.

      - ### App resource suggestions in AIRA chat <Pill type="web" />

        Type to search and select app resources — variables, widgets, and APIs — directly within the AIRA chat panel.

      - ### WM AI Assistant runs on Python backend <Pill type="web" />

        The WM AI Assistant server has been rewritten in Python, improving response performance and enabling deeper agent extensibility.

      - ### Automatic sensitive data redaction in AIRA <Pill type="web" />

        Sensitive content in conversation context is now redacted at the assistant level before being forwarded to agents.
    </Accordian>
  </TabItem>

  <TabItem name="Enhancements">
    <Accordian title="User Interface">
      - ### Bind support for data table advanced settings <Pill type="web" />

        Properties in the data table's advanced settings dialog now support bind expressions.

      - ### Upgraded to Angular 20 <Pill type="web" />

        Generated Angular apps now target Angular 20, bringing improved build performance and alignment with the latest framework release.

      - ### UI library dependency upgrades <Pill type="web" />

        Frontend library dependencies have been updated to their latest stable versions.
    </Accordian>

    <Accordian title="Backend">
      - ### Backend library upgrades

        Runtime backend dependencies — including jgit, Jackson BOM, Commons Codec, and Gson — have been updated to their latest stable versions.

      - ### Agents use file system tools instead of codebase index <Pill type="web" />

        Agents now browse and read project files using grep, glob, and read tools, replacing the previous codebase indexing approach for more accurate file lookup.

      - ### Image input support for A2A agent requests

        A2A clients can now include images in agent requests, either as a pre-uploaded file reference or as inline base64-encoded data.
    </Accordian>
  </TabItem>

  <TabItem name="Bug Fixes">
    <Accordian title="Backend">
      - ### Bitbucket Cloud workspace listing API updated

        Fixed Bitbucket Cloud integration by replacing the deprecated workspace listing endpoint with the current supported API.
    </Accordian>
  </TabItem>
</TabsWrapper>
