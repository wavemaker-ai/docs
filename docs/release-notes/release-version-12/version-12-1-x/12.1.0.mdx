WaveMaker AI 12.1.0 upgrades Angular apps and Studio to Angular 22, extends React Native apps with shared sign-in sessions and runtime environment profiles.

For details about the technology stack upgrades, refer to [Technology Stack](/tech-stack?v=12-1-0).

## 12.1.0

*Release date: 19 October 2026*

<ReleaseNotesTabs>
  <TabItem name="Features">
    <Accordian title="User Interface">
      - ### Media query support in style classes <Pill type="mobile" />

        Style classes in React Native apps now support media queries, so you can define base styles and override them for different device sizes, such as phone and tablet, using project-wide screen width breakpoints.

        For writing media queries, screen size ranges, and adaptive layout patterns, see the [Documentation](../../../user-interfaces/mobile/develop/working-with-layouts/adaptive-layout-with-media-queries).

      - ### Pull-to-refresh support <Pill type="mobile" />

        Users can now swipe down on a page to refresh its content in React Native apps, with an optional custom Lottie animation as the refresh indicator and an `onPulltoRefresh` event for custom refresh logic.

        Set `pulltorefresh` to `true` in `wm_rn_config.json` to enable it for the app, and set the `pulltorefresh` property on the page content component to turn it off for a page.

        For setup steps, the custom refresh animation, and turning it off for a page, see the [Documentation](../../../user-interfaces/mobile/develop/app-configuration/pull-to-refresh).
    </Accordian>

    <Accordian title="Platform">
      - ### Shared sign-in session with external websites <Pill type="mobile" />

        React Native apps and external websites that use the same identity provider now share a single sign-in session through the system browser, so users who sign in to the app stay signed in on the website.

        Set `authMode` to `auth_session` in `browserConfig` of `wm_rn_config`.

      - ### Multiple environment profiles in mobile builds <Pill type="mobile" />

        A single mobile app build can now carry multiple environment profiles, such as stage, test, and production, and switch between them at runtime without a rebuild or reinstall.

        Select the profiles to bundle in `Enabled Profile(s)` and set the first-launch profile in `Default Profile` under Build Preferences → Application Properties.

        For adding profiles, reading their values, and switching between them at run time, see the [Documentation](../../../user-interfaces/mobile/develop/app-configuration/multi-profile-environments).

      - ### Custom Metro configuration <Pill type="mobile" />

        Supply additional Metro settings for React Native apps, which WaveMaker merges into the default Metro configuration at build time.

        Create `custommetro.config.js` in `src/main/webapp` and export an async function that modifies and returns the base `config`.

        For setup steps and examples, including Sentry, see the [Documentation](../../../user-interfaces/mobile/device-capabilities-mobile/custom-metro-config).

      - ### Custom providers for React Native apps <Pill type="mobile" />

        Wrap your React Native app with custom providers, so you can use libraries that need a top-level provider, such as `QueryClientProvider` from TanStack Query.

        Create `customapp.wrapper.js` in `src/main/webapp` and export a default component that wraps its `children` with your providers.

        For setup steps and a TanStack Query example, see the [Documentation](../../../user-interfaces/mobile/device-capabilities-mobile/custom-app-wrapper).

      - ### New Preview (opt-in) <Pill type="mobile" />

        Try the new preview experience for React Native apps, which shows your changes faster while you build and test your app.

        To turn it on, add `"profile": "new-preview"` to `wm_rn_config.json`.

      - ### Responsive pages with WaveMaker AI <Pill type="web" />

        WaveMaker AI builds new web pages, or updates existing ones, to adapt across desktop, tablet, and mobile when you ask for responsiveness in the prompt.
    </Accordian>

  <TabItem name="Enhancements">
    <Accordian title="User Interface">
      - ### Angular 22 and frontend library upgrades <Pill type="web" />

        Generated Angular apps move from Angular 21 to Angular 22, keeping apps aligned with the latest framework release. ngx-bootstrap has been updated to its matching major version. WaveMaker Studio itself has also been upgraded from Angular 21 to Angular 22.

        <br />

        :::warning Action required: Node.js upgrade
        Node.js for Angular apps is updated from **22.18.0** to **22.22.3**. Upgrade Node.js to 22.22.3 in your local and CI/CD build environments before building Angular apps.
        :::

        For the exact versions, see the [12.1.0 technology stack](/tech-stack?v=12-1-0).

      - ### Entry animation inside bottom sheets <Pill type="mobile" />

        Accordions, panels, and other components loaded inside a bottom sheet now animate in from the bottom, matching standard bottom sheet behavior on mobile.

      - ### Ellipsis modes for the Label component <Pill type="mobile" />

        The Label component now supports ellipsis at the start, middle, or end of truncated text in React Native apps.

        Set `ellipsizemode` to `head`, `middle`, or `tail`.

      - ### Swipe events on page content <Pill type="mobile" />

        Fixed the `onSwipeLeft` and `onSwipeRight` events on the page content component not firing when a user swipes left or right.

      - ### Custom page transition animations <Pill type="mobile" />

        Customize the animation used when navigating between pages, such as fade, slide, reveal, or scale, with a single app-level setting that applies to every page navigation.

        Set `pageTransitionAnimation` in `wm_rn_config.json`, for example `slide_from_right`.

      - ### Background image blur effect <Pill type="mobile" />

        Apply a blur effect to a component's background image in React Native apps, with an intensity from 0 to 100, without blurring the component's content.

        Set the `backdrop-filter` style property to a blur value, for example `backdrop-filter: blur(10px)`.

      - ### React App Component properties aligned with Angular apps <Pill type="web" />

        Width and height, Text, Label, Icon, HTML, Iframe, and Chips components in React apps now handle their properties and accessibility attributes the same way as in Angular apps.

      - ### Global Page Cache setting <Pill type="mobile" />

        Enable or disable Page Cache for every page in an application from a single application-level setting, instead of updating each page individually.

      - ### Two-way binding for more form components <Pill type="web" />

        Checkbox, Checkbox Set, Switch, Currency, and Radioset components in React apps now support two-way binding, matching Angular apps.
    </Accordian>

      - ### Removed deprecated agents for new chats

        WaveMaker Agent, WaveMaker UI Expert, and Backend Expert Agent are deprecated and no longer offered when you start a new chat, which now starts with WaveMaker Assistant. Chats you already started with them can continue.

      - ### WaveMaker AI Assistant keeps working after logout or switching Teams

        WaveMaker AI Assistant now keeps working on a task when you log out or switch Teams mid-conversation, so you can see the result when you come back.

  <TabItem name="Bug Fixes">
    <Accordian title="User Interface">
      - ### Keyboard next action across input fields <Pill type="mobile" />

        Fixed the keyboard's next action so users can move to the next input field and keep entering values without dismissing the keyboard.

      - ### Date and time picker buttons on Android <Pill type="mobile" />

        Fixed the Select and Cancel buttons on the Date and Time pickers not responding to taps on Android when the component is used inside a form.

      - ### Canvas elements overflowing with vw and vh <Pill type="mobile" />

        Fixed elements overflowing the mobile canvas, and becoming invisible or untappable, when sized with `vw` and `vh`, which no longer affect the mobile canvas.

      - ### Security updates for lodash and debug <Pill type="mobile" />

        Upgraded the `lodash` library to 4.18.1 and the `debug` library to 4.4.3 in React Native apps to address security vulnerabilities in the earlier versions.

      - ### Validation message layout shift <Pill type="mobile" />

        Fixed an empty validation message container shifting the form layout when a field has validation but no `validationmessage`.

      - ### Form field readonly property <Pill type="mobile" />

        Fixed the Form Field `readonly` property so a read-only field stays non-editable at runtime, regardless of the form's insert or edit mode.

      - ### Bottom sheet detaching on Android <Pill type="mobile" />

        Fixed the bottom sheet detaching from the bottom of the screen on Android, so it stays anchored when the keyboard opens and closes.

      - ### Read-only Chips field displays as text <Pill type="web" /> <Pill type="angular" />

        Fixed a Chips field in a read-only Live Form displaying its values as a plain string instead of as chips in Angular apps.

      - ### Minimum characters property on Chips component <Pill type="web" /> <Pill type="angular" />

        Fixed the `minchars` property on the Chips component being ignored, so suggestions appear only after the user types the minimum number of characters in Angular apps.

      - ### Live Filter resets time to zero <Pill type="web" /> <Pill type="angular" />

        Fixed the Live Filter intermittently resetting the time to 00:00 when a user first enters a value in the time dropdown in Angular apps.

      - ### Component accessibility fixes <Pill type="web" /> <Pill type="angular" />

        Fixed accessibility issues in the Table, Search, and Breadcrumb components in Angular apps.

      - ### Main page layout breaks after switching from a Partial dialog <Pill type="web" /> <Pill type="angular" />

        Fixed the Main page canvas rendering a distorted layout after switching from a Dialog component opened in a Partial page in Studio.

      - ### Hidden components in a Dialog appear after switching pages <Pill type="web" /> <Pill type="angular" />

        Fixed an issue where components inside a Dialog with the **Show** property set to `false` became visible on the canvas after switching pages and returning to the original page in Studio, even when **Show Hidden Elements** was disabled. These components now remain hidden across page switches.

      - ### PATCH API path parameters missing in variable inputs <Pill type="web" /> <Pill type="angular" />

        Fixed path parameters not appearing as inputs in the Data tab of a Web Service variable for an imported PATCH API.
    </Accordian>
