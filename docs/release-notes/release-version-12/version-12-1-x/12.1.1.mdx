    <Accordian title="Platform">
      - ### Expo SDK 57 upgrade <Pill type="mobile" />

        React Native apps now use Expo SDK 57 with React Native 0.86.3 and React 19.2, and the Audio and Video components play through `expo-audio` and `expo-video` instead of the deprecated `expo-av`.

        Building these apps requires Node.js 22.22.3 or later.

        For the exact versions, see the [12.1.1 technology stack](/tech-stack?v=12-1-1). For changes in this Expo release, see the [Expo SDK 57 changelog](https://expo.dev/changelog/sdk-57).

      - ### ESLint validation when generating React Native apps <Pill type="mobile" />

        WaveMaker can now run ESLint on your project source files while generating the React Native app, so code issues are caught before the build. If ESLint reports errors, the export fails.

        Enable ESLint and configure its rules in the project's Build Preferences under Settings. Existing projects are not affected until you enable it.

      - ### Left nav accuracy in Screenshot to Code <Pill type="web" />

        Screenshot to Code now reproduces the sidebar in your screenshot more closely, matching its background, row height, borders, and colours, and leaves out WaveMaker's default right-hand divider and indicator bar unless the design shows them.

        [Documentation](../../../developing-with-agents/build-with-agents/screenshot-to-code#left-navigation)

      - ### Current page highlighting in generated left navs <Pill type="web" />

        Screenshot to Code now links each left nav item to its page, so the item for the open page is highlighted on every page that uses the nav.

        [Documentation](../../../developing-with-agents/build-with-agents/screenshot-to-code#nav-items-and-the-current-page)
    </Accordian>
